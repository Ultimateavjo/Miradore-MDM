# Miradore-MDM
Mobile Device Management project


<h2>Description</h2>
Project consists of mobile device management running through the Miradore application. Two devices will be controlled to simulate small enterprise or startup environment, where the company has a byod policy. The devices include android cell phone, one plus phone, and a apple deivce, ipad pro (2015). 
<br />


<h2>Languages and Utilities Used</h2>
- <b>One Plus 8T</b>
- <b>Ipad pro (2015)</b>

<h2>Environments Used </h2>

- <b>Miradore</b>
